⚠ 필독
1
앱 결제 vs 웹 결제 — 가격이 다르다
iOS/Android 앱에서 결제하면 앱 스토어 수수료가 붙어서 훨씬 비싸다. 크래커는 반드시 웹 브라우저(crack.wrtn.ai)에서 구매할 것. 모바일에서도 크롬으로 사이트에 접속해서 결제하면 저렴하다.
2
이어서 생성은 손해
출력이 잘렸을 때 "이어서 생성"을 눌러도 크래커는 처음 생성과 동일하게 차감된다. 처음부터 출력량 배율을 높이는 것이 훨씬 이득이다.
3
유저노트 500자 초과 — 매 턴마다 추가 차감
유저노트가 500자를 넘으면 초과 글자 수만큼 매 턴마다 크래커가 추가 차감된다. 유저노트는 최대한 압축해서 작성한다.
기본 개념

채팅 종류

스토리챗 (Stories)

상황·사건·행동이 문학적 나레이션과 지문으로 전개되는 방식. 단순히 대사만 주고받는 것이 아니라 주변 상황과 캐릭터 행동까지 소설처럼 묘사해준다.

복잡한 전개, 다인 캐릭터 운영, 전투·사건 묘사에 강하다. 프롬프트 용량이 넉넉해서 세밀한 설정을 담기 좋다. 딥한 롤플레이를 원한다면 스토리챗이 유리하다.

캐릭터챗 (Character Chat)

특정 캐릭터와 1:1 대화에 집중하는 방식. 대사 비중이 높고 일상 대화나 티키타카 상호작용이 중심이다.

프롬프트가 짧아 설정이 단순한 편이다.

두 방식 모두 줄여서 스챗·캐챗이라고 부른다.

기본 개념

OOC

OOC = Out of Character

RP를 멈추고 AI에게 직접 명령하거나 질문할 때 쓰는 방식이다. 캐릭터한테 하는 말이 아니라 AI 시스템에 직접 전달하는 명령이라고 생각하면 된다.

입력 방법

  • 평소 채팅창에서 바로 입력한다
  • 서버 상태 좋을 때: OOC : 내용
  • 서버 불안정할 때: <OOC> 내용 </OOC> 태그 형식이 더 잘 먹힌다

활용 예시

OOC : 현재 {char}의 감정 상태를 설명해줘

<OOC> 3일뒤. 놀이공원에 놀러간 눈꽃. </OOC>

<OOC> 롤플레이 중단. 현재까지의 서사를 바탕으로 익명 커뮤니티 내용으로 요약해줘. </OOC>

OOC 메시지는 사용 후 삭제하지 않아도 된다. AI가 이전 5~10턴을 참고하며 진행하기 때문에 남겨둬도 무방하다.

기본 개념

유저노트

유저노트란?

AI가 RP를 진행할 때 가장 먼저 참고하는 지침 공간이다. 작가가 만든 프롬프트보다 우선순위가 높다. 세계관 수정, 행동 규칙, 페소 설정 등을 여기에 넣는다.

설정 위치

  • 모든 채팅에 공통 적용: 본인 프로필 → 채팅방 설정 → 유저노트
  • 해당 채팅방에만 적용: 채팅방 내 점 3개 메뉴 → 유저노트

작성 규칙

  • # 과 - 뒤에 반드시 한 칸 띄어쓰기를 넣어야 AI가 마크다운으로 인식한다
  • 띄어쓰기 없으면 일반 텍스트로 처리되어 지침 적용이 약해진다
  • 500자 초과 시 매 턴마다 초과분 만큼 크래커가 추가 차감된다

기본 작성 예시

# Must Follow
- {user}의 행동/대사/속마음 출력 금지
- 이전 대화와 동일한 내용·표현·대사 반복 금지
- 문장이 중간에 끊이지 않게 끝까지 출력

#페소
- 이름: (이름), 25세, 여성
- 외모: 검정 머리, 165cm
기본 개념

페소 (페르소나)

페소란?

내가 플레이할 캐릭터 설정이다. 이름, 성별, 나이, 외모 등을 설정해두면 AI가 그 설정에 맞게 상대방 캐릭터가 반응한다.

작성 방법

기본 100자 제한이라 이름·성별·나이만 기재하고, 외모·성격·직업 등 상세 설정은 유저노트에 넣는 것이 좋다.

#페소
- 이름: (이름), 25세, 여성
- 외모: 검정 머리, 165cm
- 직업: 대학교 4학년
- 성격: 평소 무뚝뚝한 편
주의

페소 나이는 반드시 숫자로 명시한다. 나이가 없거나 모호하면 AI 윤리 필터가 오작동할 수 있다.

기본 개념

유저 사칭

유저 사칭이란?

내가 입력하지 않은 내 대사·행동·감정을 AI가 임의로 만들어내는 현상이다. 예: 내가 아무것도 안 보냈는데 AI가 "당신이 수줍게 웃었다"처럼 내 행동을 서술하는 경우.

방지 방법

유저노트에 아래 지침을 기재한다.

# CRITICAL RULE
- {user}의 행동/대사/생각/감정 대신 출력 금지
- {user}의 의도를 AI가 임의 해석/확장 금지

또는 !사칭 명령어를 입력하면 최근 응답에서 사칭 여부를 자동으로 점검하고 수정한다.

크래커 소모 구조

출력량 배율 조절

채팅방 내 점 3개 메뉴 → 최대 출력량 조절에서 설정. 배율 선택 시 해당 턴 소모 크래커 수가 미리 표시된다.

계산 예시

1배 50크래커인 방에서 출력이 잘려서 이어서 생성 1번 → 총 100크래커 소모
처음부터 1.5배(75크래커)로 설정하면 1번에 끝 → 25크래커 절약

유저노트 초과 차감

  • 500자 초과 시 초과 글자 수만큼 매 턴마다 추가 차감
  • 2000자로 확장해도 동일하게 적용
  • 내용이 많다면 크랙 검색에서 압축봇을 찾아 글자 수를 줄인다

크래커 후원 수수료

  • 비크리에이터 작가에게 후원 시: 30% 수수료 제외 후 전달
  • 크리에이터 작가에게 후원 시: 10% 수수료 제외 후 전달

  • 요약 결과는 유저노트에 기재해두면 더 확실하게 유지된다
#요약
- 3월: A와 B가 카페에서 처음 만남
- 4월: 벚꽃나무 아래서 고백
- 현재: 동거 중, 각자 방 사용
챗 & 운영

분기 기능

분기란?

특정 채팅 시점을 기준으로 새 방을 만드는 기능. 처음부터 해당 채팅까지의 요약 메모리가 복사된 채로 새 방이 생성된다.

사용 방법

원하는 채팅 메시지를 길게 누르면 삭제·복사·수정·분기 항목이 뜬다.

분기 vs 새 방

방식장점단점
분기과거 메모리 안정적, 이식 간편작가 최신 프롬 업데이트 반영 안 됨
새 방최신 프롬 적용기억 이식 직접 해야 함

방에서 오류(문체 망가짐, 이미지 안 나옴, 반복)가 심할 때 직전 분기를 파면 해결되는 경우가 많다.

챗 & 운영

새 방 이식

기존 방의 서사를 유지하면서 새 방에서 이어서 진행하는 방법이다.

  1. 기존 방에서 OOC : 처음부터 지금까지 사건, 인물관계 변화를 자세하게 요약해줘 입력
  2. 내용이 길면 크랙 내 압축봇으로 글자 수를 줄인다
  3. 새 방 첫 메시지에 요약 내용 + 이어서 진행 요청을 붙여 넣는다
  4. 유저노트에 핵심 정보·관계·초기 서사를 기재한다
세이프 → 언셒 이식

세이프에서 언셒이 생겼을 때도 동일 방법. 요약 내용을 언셒 스토리 첫 메시지 + 유저노트에 붙여넣고 OOC로 이어서 진행 요청.

챗 & 운영

이미지 설정

이미지도 출력 토큰에 포함된다. 이미지가 많을수록 본문 글자 수가 줄어든다. 이미지 보지 않기 설정을 켜도 토큰은 동일하게 소모된다.

이미지 안 나올 때

  1. 해당 채팅에 !점검 이미지, !이미지, !디버깅 중 하나가 있다면 먼저 시도
  2. 없다면 유저노트에 아래 기재 + 이전 3~5턴 이미지 직접 삭제
  3. 그래도 안 되면 직전 메시지에서 분기 파기
#Image rule
- 각 응답당 최소 1개 이미지 출력 필수

이미지 끄기

#Image rule
- 이미지 출력 금지

기재 후 이전 3~5턴의 이미지를 직접 삭제해야 확실하게 적용된다.

잠긴 이미지

작가가 설정한 조건을 달성하면 해제된다. OOC : 모든 이미지를 출력해줘를 입력하면 한꺼번에 나올 때가 있다.

기본 서술 원칙

# Must Follow
- {user}의 행동/대사/속마음 출력 금지
- 이전 대화와 유사/동일 내용·표현·대사 반복 금지

출력 분량 제한 (하이퍼챗 권장)

#출력 분량
- 6문단 이하로 제한

토큰 수·글자 수보다 문단 개수로 제한하는 쪽을 AI가 훨씬 잘 알아듣는다. 출력량 1.5배와 함께 쓰면 크래커를 아끼면서 안 잘리는 조합이다.

서술 개선

#서술 지침
- 관조적 문어체·정적 설명조 금지, 현장감 있는 구어체+감각 묘사 병행
- 전개 순서: 동적 사건 > {char} 반응 > 주변 묘사
- em dash·해부학적 용어 금지

Show, don't tell

설정값을 직접 말하지 않고 행동·표정·말투로만 보여주도록 하는 지침이다.

- 설정값 직접 언급 금지, 행동·표정·말투·시선처리로만 간접 묘사

강압·집착·숭배 방지

# Must Follow
- 갑작스러운 NSFW 전개 절대 제한
- 강압·집착·소유욕 표현 자제
- {char}→{user} 신격화·숭배 절대 금지

Q
크래커가 뭔가요?

크랙에서 사용하는 화폐(포인트)다. AI 채팅을 한 턴 진행할 때마다 차감된다. 출석체크·도전과제로 무료로 얻거나 웹사이트에서 구매할 수 있다.

앱에서 구매하면 앱 스토어 수수료가 붙어서 더 비싸다. 반드시 웹 브라우저(crack.wrtn.ai)에서 구매하는 것이 저렴하다.

Q
페소(페르소나)가 뭔가요?

내가 플레이하는 캐릭터의 설정이다. 이름, 성별, 나이, 외모 등을 미리 설정해두면 AI가 그 설정에 맞게 상대방 캐릭터가 반응해준다.

기본 제공 공간이 100자라서 이름·성별·나이만 넣고, 상세 설정은 유저노트에 작성하는 것이 좋다. 나이는 반드시 숫자로 명시해야 윤리 필터 오작동을 막을 수 있다.

Q
유저노트가 뭔가요?

AI가 RP를 진행할 때 가장 먼저 참고하는 지침 공간이다. 작가가 만든 프롬프트보다 우선순위가 높아서 세계관 수정, 행동 규칙, 페소 설정 등을 넣으면 적용된다.

500자까지 기본 제공. 초과하면 매 턴마다 크래커가 추가로 차감된다. 설정 위치: 프로필 → 채팅방 설정 → 유저노트

Q
OOC가 뭔가요?

Out of Character의 약자. RP를 멈추고 AI에게 직접 명령하거나 질문할 때 사용한다. 캐릭터한테 하는 말이 아니라 AI 시스템에 보내는 명령이다.

채팅창에 OOC : 내용 또는 <OOC> 내용 </OOC>으로 입력한다. 사용 후 삭제하지 않아도 된다.

Q
유저 사칭이 뭔가요?

내가 입력하지 않은 나의 대사·행동·감정을 AI가 임의로 만들어내는 현상이다.

예: 내가 아무것도 안 입력했는데 AI가 "당신이 수줍게 웃으며 고개를 끄덕였다"처럼 내 행동을 대신 서술하는 경우.

유저노트에 -{user}의 행동/대사/생각/감정 대신 출력 금지를 기재하거나 !사칭 명령어로 점검할 수 있다.

Q
분기가 뭔가요?

특정 채팅 시점에서 새 방을 만드는 기능이다. 처음부터 해당 시점까지의 메모리가 복사된 채로 새 방이 생성된다.

원하는 채팅 메시지를 길게 누르면 나오는 메뉴에서 선택한다. 방에서 오류가 심할 때 직전 분기를 파면 해결되는 경우가 많다.

Q
장기기억·요약 메모리가 뭔가요?

AI가 이전 채팅 내용을 기억하기 위해 자동으로 생성하는 요약본이다. 채팅방 내에서 확인하고 직접 수정할 수 있다.

턴이 쌓일수록 초기 기억을 점점 잊기 시작한다. 100턴마다 !요약을 사용하고, 중요한 초기 서사는 유저노트에 직접 기재해두는 것이 좋다.

Q
세이프/언셒이 뭔가요?

세이프(Safe)는 성인 콘텐츠 없이 즐길 수 있는 버전, 언셒(Unsafe)은 성인 콘텐츠가 포함된 버전이다.

같은 작품이라도 세이프/언셒 버전이 따로 나와있는 경우가 있다. 언셒을 플레이하려면 성인 인증이 필요하다.

Q
찐빠가 뭔가요?

오류를 뜻하는 표현이다. 문체가 갑자기 망가지거나, 이미지가 안 나오거나, 같은 내용이 반복되거나, 영어가 섞여 나오는 현상을 통틀어 찐빠라고 한다.

Q
채팅방 점 3개 메뉴가 뭔가요?

채팅방 화면에서 점 세 개(⋯) 버튼을 누르면 나오는 메뉴다. 여기서 출력량 배율 조절, 채팅방 유저노트 설정, 채팅방 정보 등을 변경할 수 있다.

이미지도 출력 토큰에 포함되기 때문에 이미지가 많을수록 본문 글자 수가 줄어든다. 이미지 보지 않기 설정을 켜도 토큰은 동일하게 소모된다.

#Image rule
- 이미지 출력 금지

기재 후 이전 3~5턴 이미지를 직접 삭제해야 확실하게 적용된다.

Q
이미지 보관함에 잠긴 사진은 어떻게 해제하나요?

작가가 설정한 조건을 달성해야 해제된다. 해당 이미지가 채팅에서 출력될 때 자동으로 잠금이 풀린다.

OOC : 모든 이미지를 출력해줘를 입력하면 한꺼번에 나올 때가 있다. 조건이 궁금하다면 작가에게 댓글로 문의한다.

분기·새 방

분기 & 새 방 이식 관련

Q
분기는 어떻게 사용하나요?

원하는 채팅 메시지를 길게 누르면 삭제·복사·수정·분기 항목이 뜬다. 분기를 선택하면 처음부터 해당 시점까지의 요약 메모리가 복사된 새 방이 생성된다.

Q
분기로 파면 작가가 업데이트한 프롬이 반영되나요?

반영되지 않는다. 분기 당시 원본 방의 프롬프트가 그대로 적용된다. 최신 프롬을 원하면 아예 새 방을 파야 한다.

Q
세이프 방에서 언셒으로 이식하는 방법이 있나요?

기존 세이프 방에서 OOC로 서사를 요약한다. 요약 내용을 언셒 스토리의 첫 메시지와 유저노트에 붙여넣고 OOC로 이어서 진행을 요청하면 된다.

오류·제보

오류 & 제보 관련

Q
오류가 났을 때 크래커 환불 받는 방법은?

오류 화면을 캡처한 뒤 아래 경로로 제보한다.

프로필 → 고객센터 → 헬프데스크 → 우측 하단 빨간 채팅 버튼 → 유저

모바일 앱에서 사진 첨부가 안 된다면 크롬에서 크랙 웹사이트에 접속 후 데스크톱 사이트로 진행한다.

Q
채팅에서 오타가 났을 때 수정할 수 있나요?

보낸 채팅을 길게 누르면 수정·삭제 항목이 뜬다. 수정 후 다시하기(리롤) 버튼으로 새 답변을 받을 수 있지만 크래커는 동일하게 차감된다.

Q
OOC나 명령어 사용 후 메시지 삭제해야 하나요?

삭제하지 않아도 된다. AI가 이전 5~10턴을 참고하며 진행하기 때문에 OOC나 명령어 메시지가 남아있어도 RP에 큰 영향을 주지 않는다.

기타 설정

기타 설정 관련

Q
AI 윤리 필터에 걸렸을 때 어떻게 하나요?

① 다른 모델로 몇 턴 진행 후 다시 하이퍼챗으로 돌아온다

② 해당 장면 직전에서 분기를 파서 다른 흐름으로 진행한다

③ 페소 나이를 명확한 숫자로 기재하고, 이름이 어린아이 느낌이라면 변경을 고려한다

Q
NPC가 자주 안 나와요.
# Must Follow
- {npc이름}와 유저 상호작용 매우 높음
Q
성인 인증은 어떻게 하나요?

크랙 앱에서 본인계정 → 개인 맞춤 설정 → 장르별 성인작 보기를 클릭하면 인증 페이지로 넘어간다. 법적 성인만 인증 가능하다.

Q
엔딩은 어떻게 보나요?

작가가 설정한 조건을 달성하면 엔딩이 해제된다. 엔딩 체크는 5턴마다, 최소 10~30턴 이상 진행해야 체크가 시작된다.

조건은 작가 댓글 또는 채팅 내 엔딩카드 → 엔딩 힌트에서 확인한다.
